Organisation & Fonctionnement Interne

Afin de mener à bien le développement de la plateforme IFRI_MentorLink, nous avons adopté une méthodologie Agile simplifiée centrée sur la communication continue et la collaboration active.

Outils Collaboratifs

  • Git & GitHub : Dépôt centralisé avec politique de Pull Requests pour valider les modifications de code et éviter les conflits sur la branche principale.
  • Trello : Suivi des tâches organisé en colonnes (À faire, En cours, À tester, Terminé) pour visualiser la progression globale en temps réel.
  • WhatsApp : Espace privilégié de discussion rapide pour débloquer les anomalies techniques quotidiennes.

Découpage des Tâches

La répartition a suivi une logique de composants interconnectés, où les développeurs backend fournissaient les APIs et les architectures de données tandis que les développeurs frontend concevaient l'interface interactive correspondante.

Description de la Conception

Modèle Conceptuel de Données (MCD - ASCII)

Voici l'agencement logique des tables stockées dans PostgreSQL :

+-------------------------+ +-------------------------+ | users | | matieres | +-------------------------+ +-------------------------+ | id (PK) | | id (PK) | | email (Unique) | | nom (Unique) | | telephone (Unique) | +-------------------------+ | nom, prenom | ^ | filiere, niveau | | | disponibilites (JSONB) | +------------+------------+ +-----------+-------------+ | | | | | | 1:N | 1:N | 1:N v | | +-----------+-------------+ | | | offres_mentorat |------------+ | +-------------------------+ | | id (PK) | | | auteur_id (FK -> users) | | | type, format, statut | | +-------------------------+ | | +-------------------------+ +-------------------------+ | matchings |------------+ matching_matieres | +-------------------------+ +-------------------------+ | id (PK) | | id (PK) | | mentor_id (FK) | | matching_id (FK) | | mentore_id (FK) | | matiere_id (FK) | | score_compatibilite | +-------------------------+ +-------------------------+ +-------------------------+ +-------------------------+ | conversations | | messages | +-------------------------+ +-------------------------+ | id (PK) | 1:N | id (PK) | | date_creation |----------->| conversation_id (FK) | +-------------------------+ | auteur_id (FK) | | contenu, date_envoi, lu | +-------------------------+

Architecture Logicielle (MVC Django)

L'application respecte rigoureusement le patron MVT (Modèle-Vue-Template) de Django :

  • Les Modèles : Représentent les structures de données SQL (utilisateurs, matières, offres, conversations, messages) avec gestion des types, validations et contraintes associées.
  • Les Vues : Portent la logique métier en traitant les requêtes HTTP, interrogeant la base de données et calculant la compatibilité à l'aide de l'algorithme de matching.
  • Les Templates : Fichiers HTML dynamisés par le moteur de rendu Django, stylisés à l'aide de CSS moderne pour fournir une expérience interactive haut de gamme.

Instructions de Déploiement

  1. Initialisation : Créez et activez un environnement virtuel Python 3.10+ : python -m venv venv && source venv/bin/activate.
  2. Installation : Installez les paquets requis : pip install -r requirements.txt.
  3. Configuration : Copiez le fichier .env.example en .env et ajustez les variables (identifiants PostgreSQL et Redis).
  4. Base de données : Créez la base de données dans PostgreSQL et appliquez les fichiers de structure initiaux : python manage.py migrate.
  5. Lancement : Exécutez le serveur de messages Redis (redis-server) puis démarrez le serveur ASGI de développement : python manage.py runserver ou daphne mentorlink.asgi:application.

Manuel d'Utilisation de l'Application

1
Création de Compte & Profil

Accédez à la page d'inscription pour créer un compte avec vos informations d'étudiant (nom, prénom, filière et niveau). Indiquez directement vos matières maîtrisées (compétences) et celles où vous souhaitez progresser (lacunes).

2
Grille de Disponibilités Interactive

Depuis l'édition de profil, utilisez la grille hebdomadaire pour cliquer sur vos plages de cours libres. Ces données seront stockées au format JSONB pour permettre des calculs de concordance immédiats.

3
Tableau de Bord & Suggestions de Matching

Votre tableau de bord affiche vos statistiques personnelles ainsi que les suggestions de mentors ou tutorés calculées en temps réel par notre algorithme (pondéré sur vos intérêts croisés et disponibilités communes).

4
Messagerie Instantanée Temps Réel

Cliquez sur "Contacter" pour ouvrir une discussion instantanée. Les messages s'affichent instantanément à l'aide de Django Channels sans nécessiter de rafraîchissement manuel de la page. Les notifications de messages non lus apparaissent en haut dans la barre globale.
